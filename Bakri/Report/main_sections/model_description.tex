\subsection{Model Scaling and Interpretation}

The model can be scaled so that each car occupies around $7.5$ m of road which is the length of one cell.
As the average velocity of cars in free traffic is $4.5$ cells per time step it should correspond to around $120$ km/h (in Germany), which is a reasonable speed for free traffic on a motorway, naturally we arrive at a time for iteration of
\begin{equation}
 7.5 \frac{\text{m}}{\text{cell}} \times 4.5 \frac{\text{cells}}{\text{time-step}}/(120/3.6) \frac{\text{s}}{\text{m}} \approx 1.0 \text{ s}
\end{equation}
\cite{nagelCellularAutomatonModel1992}.
 As this model is scalable to different scenarios there is not a need to non-dimensionalise the model, we can simply use the above scaling to interpret the results in real world terms
